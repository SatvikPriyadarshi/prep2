# Topic 9: Web Technologies (Previous Year Pattern)

## 📝 Quick Revision Cheat Sheet (Before you start)

- **HTML:** 
HyperText Markup Language. Defines the structure of web pages.
- **Tags:** <html>, <head>, <body>, <h1>-<h6>, <p>, <a>, <img>, <ul>, <ol>, <table>.
- **CSS:** 
Cascading Style Sheets. Controls the presentation (layout, colors, fonts).
- **Selectors:** element, .class, #id. Box Model: content, padding, border, margin.
- **JavaScript:** 
Client-side scripting language for dynamic behavior.
DOM manipulation, event handling, form validation. let (block-scoped), var (function-scoped), const (constant).
- **XML:** 
Extensible Markup Language. Designed to store and transport data .
Self-descriptive, user-defined tags, case-sensitive .
- **Web Design Principles:** 
W3C standards, accessibility, responsive design, separation of concerns (HTML, CSS, JS).
- **Web Browsers (2026):** 
- **AI-Powered:** OpenAI's Atlas (now merged into ChatGPT app) , Perplexity's Comet, Opera's Neon, The Browser Company's Dia .
- **Privacy-Focused:** Brave (ad blocking + BAT rewards), DuckDuckGo (tracker blocking), Ladybird (built from scratch) .
- **Mindful:** Opera Air (breathing exercises, focus reminders) .
