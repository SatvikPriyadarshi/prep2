# Topic 10: Computer Architecture (Previous Year Pattern)

## 📝 Quick Revision Cheat Sheet (Before you start)

- **CPU Components:** Control Unit (CU), Arithmetic Logic Unit (ALU), Registers.
- **CU:** Directs operations, decodes instructions, controls data flow .
- **ALU:** Performs arithmetic and logical operations (comparisons, calculations) .
- **Registers:** High-speed storage inside the CPU (e.g., Program Counter, Accumulator).
- **Memory:** Volatile (RAM - loses data on power off) vs. Non-volatile (ROM, Hard Disk - retains data) .
- **Bus:** Address Bus, Data Bus, Control Bus.
- **Interrupts:** Signals that pause the CPU's current task to handle an event.
- **Virtual Memory:** Uses secondary storage (disk) to extend main memory; relies on paging and Locality of Reference .
